REFERENCE: light_setup(direction, first) in tool/_harden_one.py
------------------------------------------------------------------------
  dir≈180 → light_xy=(950, first.y), tip/light_m=(1028, first.y), beam=(-1,0), side=east
  dir≈0   → light_xy=(130, first.y), tip/light_m=(52, first.y),  beam=(1,0),  side=west
  dir≈90  → light_xy=(first.x, 130), tip/light_m=(first.x, 52),  beam=(0,1),  side=north
  else270 → light_xy=(first.x, 1790), tip/light_m=(first.x, 1868), beam=(0,-1), side=south
  Note: lightSources[].position stores light_xy (fixture), simulation uses
  mounted_origin(pos, direction) which snaps tip to WALL_INSET=52 on the
  entry wall (matching light_m). Euclidean light_xy→first hinge is therefore
  |950-first.x| for east starts, |130-first.x| west, |130-first.y| north,
  |1790-first.y| south — IF first hinge shares the axis coordinate.
  candidate_starts places first hinge on XS[-1]/XS[0]/YS[0..1]/YS[-1..-2],
  so gap depends on grid edge vs fixed light fixture coords.

ROOT CAUSE
------------------------------------------------------------------------
light_setup uses FIXED fixture coords (950/130/130/1790) independent of first.x/y
beyond sharing the cross-axis. candidate_starts pins first hinge to the EDGE
lattice column/row:

  east:  first≈(970–980,y) vs light x=950  → gap 20–30, often axial NEGATIVE
         (fixture past hinge along beam; tip@1028 → hinge@970 → fixture@950)
  west:  first≈(220,y) vs light x=130       → gap ~90 (OK-ish, axial+)
  north: first≈(x,90–110) vs light y=130    → gap 20–40, often axial NEGATIVE
  south: first≈(x,1780–1840) vs light y=1790→ gap 10–50

Contrast generate_levels_extreme.build_axis:
  first = tip + beam_dir * {450,500,550,600}  → hundreds of px of beam travel.

Many <150 levels have axial < 0: lightSources.position is PAST m1 along the
beam, so the emitter sprite sits on/beyond the first mirror (barely visible beam).

PROPOSED FIX (prefer b; do not batch-mutate yet without re-validate)
------------------------------------------------------------------------
(b1) Rewrite light_setup(direction, first) relative to first + tip:

  MIN_FIXTURE_GAP = 120.0   # lightSources.position → first hinge along beam
  MIN_TIP_GAP     = 160.0   # mounted tip → first hinge (room for visible beam)

  tip stays on wall (WALL_INSET / ROOM-WALL_INSET) as today.
  Require |first - tip| along beam >= MIN_TIP_GAP (else caller must pick
  inward first / reject start).
  light_xy = first - beam_unit * MIN_FIXTURE_GAP, clamped so it lies strictly
  between tip and first (axial > 0).
